# EVSA SHOP

Маркетплейс игровых товаров: аккаунты, буст, донат, промокоды — с безопасной сделкой (деньги в резерве до подтверждения получения).

**Демо:** https://evsey67018.github.io/evsa-shop/

> ⚠️ Это демо-версия. Все аккаунты, товары, чаты и балансы хранятся только в вашем браузере (localStorage). Деньги тестовые — настоящие платежи пока не подключены.

## Что работает в демо
- Главная: карусель баннеров, популярные игры, «Вы смотрели», премиум-товары, сайты и приложения, хиты продаж
- 22 игры и 14 сайтов/приложений, категории, фильтры (онлайн, способ получения, цена, скидка, с отзывами, сортировка)
- Страница товара: характеристики, гарантии, избранное, жалоба, продавец, отзывы, похожие товары
- Вход (демо-форма вместо Telegram Login), профиль, аватарка, баланс, история операций
- Продажа товаров (мастер, фото, PREMIUM за 19 ₽), корзина, избранное, уведомления
- Безопасная сделка: резерв → передача → подтверждение / спор → отзыв; чаты с продавцом
- Пополнение (тестовые рубли, Stars — «скоро», подарком — с проверкой админом), вывод от 15 ₽
- Поддержка с категориями обращений, реферальная ссылка, страница «Пополнение Steam» (скоро)
- Админ-панель (включается в Настройках → демо-режим администратора)
- Тёмная/светлая тема, звуки, адаптив под телефон

## Структура
